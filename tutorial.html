🚀 Parte 1 — Setup inicial

Esta parte você faz uma vez só. Depois disso, é só editar como mostrado na Parte 2 e o site atualiza sozinho.

Capítulo 1 (Setup)

Receber o arquivo ZIP e descompactar

O desenvolvedor te mandou um arquivo chamado promocoes-do-dia.zip (cerca de 250 KB) por WhatsApp, e-mail, ou outro meio.

Passo 1.1 — Salve o ZIP no Desktop

Pra não esquecer onde está, salve em Desktop (computador) ou Downloads.

Passo 1.2 — Descompacte (extrair)

  • Mac: clique duas vezes no ZIP. Ele cria a pasta Achadinhos Aline ao lado.
  • Windows: clique com botão direito → Extrair tudo → Extrair.

Passo 1.3 — Veja o que tem dentro

Dentro da pasta extraída tem estes arquivos:

📁 Achadinhos Aline (pasta no seu computador)
assetsimagens do site
config.jsconfigurações do site
index.htmlpágina principal
styles.css
script.js
vercel.json
tutorial.htmleste tutorial!
💡 Não apague nenhum arquivo! Todos são necessários pro site funcionar.
Capítulo 2 (Setup)

Criar conta no GitHub (se ainda não tem)

O GitHub é onde os arquivos do site vão ficar guardados na nuvem. É grátis pra sempre.

Passo 2.1 — Abra a página de cadastro

Acesse no navegador:

https://github.com/signup

Passo 2.2 — Preencha os dados

  1. Email: use um email que você usa de verdade (você vai precisar confirmar)
  2. Senha: 15 caracteres ou mais — anote em um lugar seguro
  3. Username: seu nome de usuário (ex: marketing-aline, achadinhosaline). Sem espaços, sem acentos.
  4. Confirme o email clicando no link que o GitHub manda
⚠️ Anote o seu username! Vai ser usado em todas as URLs do site (ex: github.com/SEU-USERNAME/promocoes-do-dia).

Passo 2.3 — Pule o questionário inicial

O GitHub vai te fazer algumas perguntas iniciais ("qual sua experiência?", etc). Pode clicar em Skip em tudo.

Passo 2.4 — Pronto!

Conta criada. Você vai ver uma tela de "boas-vindas" com o logo do GitHub no canto superior esquerdo.

🆓 GitHub é grátis pra sempre pra esse uso. Sem cartão de crédito, sem trial.
Capítulo 3 (Setup)

Criar o repositório do site no GitHub

"Repositório" é o nome chique pra "pasta na nuvem". Vamos criar um pra esse site.

Passo 3.1 — Clique em "New"

Acesse:

https://github.com/new

Passo 3.2 — Preencha o formulário

github.com/new

Repository name *

promocoes-do-dia

Description (optional)

Landing page do grupo Promoções do Dia

⚠️ Initialize this repository with:

Passo 3.3 — Configurações importantes

  1. Repository name: digite promocoes-do-dia (sem espaços, sem acentos)
  2. Escolha Public (recomendado — permite usar Vercel grátis sem limitações)
  3. NÃO marque nenhuma das opções de "Initialize" — deixe TUDO desmarcado
  4. Clique no botão verde Create repository
⚠️ Importante: NÃO marque "Add a README" nem "Add .gitignore". Se marcar, o upload do ZIP vai dar conflito.

Capítulo 6 (Setup)

Fazer o primeiro deploy (publicar o site)

Passo 6.1 — Importe o repositório do GitHub

Depois do login, a Vercel mostra uma tela de "Import Project". Vai aparecer uma lista dos seus repositórios do GitHub.

Passo 6.2 — Aceite as configurações padrão

A Vercel vai mostrar uma tela com configurações de build. Não mude nada. Só clique no botão grande Deploy.

Passo 6.3 — Aguarde ~30 segundos

Vai aparecer uma animação de fogos de artifício 🎆 quando terminar. Pronto, seu site está no ar!

Capítulo 3

Configurar o Pixel da Meta (Facebook)

O Pixel é o número que o Facebook/Meta dá pra você rastrear quem visita o site e quem clica no botão do WhatsApp.

Passo 3.1 — Pegue seu Pixel ID

  1. Entre em business.facebook.com/events_manager
  2. Crie um novo pixel (ou abra um existente)
  3. Copie o número que aparece (16 dígitos, ex: 1234567890123456)

Passo 3.2 — Cole no config.js

Edite o config.js (como no Capítulo 2), procure a linha metaPixelId e cole o número entre as aspas:

github.com/.../config.js (edição)
15// 2) META PIXEL ID
16// Cole aqui o número (16 dígitos)
17 metaPixelId: "1234567890123456",

Faça Commit changes e pronto. O pixel começa a contar automaticamente.

💡 Pode testar abrindo seu Events Manager no Facebook e olhando o card "Test Events". Visite o seu site e veja as visitas aparecerem em tempo real.
Capítulo 4

Mudar os textos da página

Você pode trocar: título, subtítulo, texto do botão verde, selo amarelo, rodapé.

Passo 4.1 — Abra o config.js e procure o bloco textos:

github.com/.../config.js
30 textos: {
31 titulo: "Promoções do Dia",
32 subtitulo: "Milhares de cupons...",
33 botaoCta: "ENTRAR NO GRUPO EXCLUSIVO",
34 selo: "100% Gratuito • Vagas limitadas",
35 rodape: "© 2026 Promoções do Dia...",
36 },

Passo 4.2 — Troque o que está entre as aspas

Cada linha funciona assim:

nome_da_coisa: "TEXTO QUE APARECE NO SITE",

Só troque o que está entre " e ". Não apague as aspas nem a vírgula!

⚠️ Se quiser usar aspas dentro do texto, use \". Por exemplo: titulo: "O \"melhor\" grupo",

Passo 5.3 — Suba a foto nova

  1. Volte pra pasta assets
  2. No canto superior direito, clique em Add file → Upload files
  3. Arraste a nova foto do seu computador pra área indicada

Trocar a logo do grupo

Mesmo procedimento do Capítulo 5, mas o arquivo é logo-grupo.png (na pasta assets).

  1. Entre na pasta assets

  3. Suba sua logo nova, garantindo que o nome é exatamente logo-grupo.png

  4. Adicione uma nova linha antes do ], final:

Remover um marketplace

Apague a linha inteira do marketplace no config.js (incluindo a vírgula). Opcional: apague também o arquivo da logo em assets/marketplaces/.

Capítulo 8

Adicionar / remover nomes do pop-up

Aquele pop-up "Fulano acabou de entrar no grupo" pega nomes aleatórios de uma lista.

  1. Edite o config.js
  2. Procure o bloco nomesPopup: (linha ~42)
  3. Adicione novos nomes entre aspas, separados por vírgula
github.com/.../config.js
42 nomesPopup: [
43 "Rafael", "Mariana", "João", "Aline",
44 "Carlos", "Beatriz", // ← novos nomes
45 ],
💡 O sistema garante que o mesmo nome nunca aparece 2 vezes seguidas. Quanto mais nomes você colocar, mais natural fica.

Capítulo 10

Voltar uma versão antiga (rollback)

Errou algo? Sem stress — dá pra voltar pra qualquer versão antiga em 2 cliques.

  1. Acesse o painel da Vercel
  2. Clique na aba Deployments
  3. Encontre a versão que estava funcionando bem
  4. Clique nos 3 pontinhos ⋯ à direita
  5. Clique em Promote to Production
  6. Confirme e pronto — site voltou em ~5 segundos

Capítulo 11

Configurar domínio próprio (opcional)

Se você comprou um domínio (ex: promocoesdodia.com.br) e quer usar no lugar de .vercel.app:

  1. Painel Vercel → Settings → Domains
  2. Digite o domínio: promocoesdodia.com.br → Add
  3. A Vercel mostra 2 registros DNS que você precisa adicionar no seu provedor (Registro.br, GoDaddy, Hostinger, etc.)
  4. Adicione lá no provedor
  5. Aguarde 5–30 minutos. A Vercel detecta sozinho e ativa HTTPS de graça.
Dúvidas frequentes

FAQ — Problemas comuns e soluções

A página apareceu toda branca/quebrada depois que editei

Geralmente acontece quando alguma vírgula ou aspa foi removida no config.js.

Solução rápida: faça o rollback (Capítulo 10) pra última versão funcionando.

A nova foto/logo não apareceu

Confira:

  • O nome do arquivo está exatamente igual ao antigo? (Ex: aline-background.jpg, letra minúscula, com hífen, sem espaço)
  • O arquivo está na pasta certa? (assets/ pra fundo/logo; assets/marketplaces/ pra logos de loja)
  • Você atualizou a página com Ctrl+F5 / Cmd+Shift+R?
O botão do WhatsApp leva pra lugar errado

Abra o config.js e confira a linha whatsappLink::

  • O link precisa começar com https://
  • Precisa estar entre aspas duplas: "https://..."
  • Não esqueça da vírgula no final
O pop-up "Fulano entrou" não aparece
  • Aguarde 3–4 segundos após abrir a página (não aparece imediato)
  • Verifique se o JavaScript está habilitado no navegador
  • Tente em modo anônimo (Ctrl+Shift+N / Cmd+Shift+N)
Como ver quantas pessoas visitaram o site?

No painel da Vercel → Analytics (menu superior). Mostra visitas, visualizações, dispositivos e países.

Free Tier dá 2.500 eventos/mês grátis — mais que suficiente pra começar.

Não consigo logar no GitHub do celular

Baixe o app oficial do GitHub na Play Store ou App Store. Ele tem o mesmo editor do site, perfeito pra editar arquivos quando estiver fora de casa.

Preciso pagar alguma coisa pra usar Vercel/GitHub?

Não. Tanto o GitHub quanto a Vercel oferecem planos gratuitos que aguentam tranquilamente o tráfego de uma landing page. Você só precisaria pagar se chegar em milhões de visitas/mês.
